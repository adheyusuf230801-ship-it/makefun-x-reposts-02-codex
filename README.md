This repository is an entry for the make.fun bounty “Get the most reposts and likes on make.fun's newest X posts,” with $500 shared across the top 50 places and $100 for first place. Entries close Saturday 28 November 2026 at 07:30 UTC. The entry is the entrant's own post on X: a quote-post of one of make.fun's newest posts, published by @mamahkinaesx3 at https://x.com/mamahkinaesx3/status/2125789183247831489, with @makefunai and the play code makefun-squash-porridge-sunrise in its text. POSTS.json names the post, and main.ts, running on Node 22 with only the standard library, validates it and copies it to the output directory the house reads. The house reads the post's engagement from X and awards 2 points per repost, 2 points per quote, and 1 point per like. The post and the account stay public until the results are out.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
